## 초록 (Abstract)

Google AI Overview와 ChatGPT 같은 생성형 엔진(Generative Engines, GEs)은 대규모 언어 모델(LLM)로 문서를 검색하고 자연어 응답을 생성하며 새로운 검색 형태로 빠르게 자리 잡았다. 이에 따라 콘텐츠 제공자들의 가시성 확보를 위한 **생성형 엔진 최적화(GEO)** 수요가 급증했다. 본 논문은 생성형 엔진이 검색된 콘텐츠를 응답에 활용할 때 어떤 선호를 보이는지 자동으로 학습하고, 이를 바탕으로 웹 콘텐츠를 재작성하는 프레임워크 **AutoGEO**를 소개한다.

AutoGEO는 먼저 프런티어 LLM에 생성형 엔진의 선호를 설명하게 하여 유의미한 선호 규칙(preference rules)을 자동 추출한다. 이어서 이 규칙을 프롬프트 기반 시스템 **AutoGEO_API**의 컨텍스트 엔지니어링에 활용하고, 동시에 규칙 기반 보상(rule-based rewards)으로 삼아 비용 효율적인 경량 모델 **AutoGEO_Mini**를 학습한다. 표준 GEO-Bench와 실제 사용자 질의로 구축한 두 신규 벤치마크(Researchy-GEO, E-commerce) 실험 결과, AutoGEO는 **검색 효용(Generative Engine Utility, GEU)을 보존하면서 GEO 지표를 평균 35.99% 향상**시켰으며, 특히 AutoGEO_Mini는 AutoGEO_API 대비 약 **0.0071배** 비용으로 기존 기준선들을 모두 능가했다.

## 1. 서론 (Introduction)

기존 GEO 접근법(Aggarwal et al., 2024; Nestaas et al., 2024)은 주로 수작업으로 설계한 휴리스틱 프롬프트에 의존하거나 적대적 명령을 주입해 가시성만 쫓았으며, 생성형 엔진의 근본적 선호나 답변 품질(효용)과의 트레이드오프를 체계적으로 이해하지 못했다.

본 논문의 3대 기여는 다음과 같다:
1. **자동 선호 규칙 추출 및 플러그인 모델(`AutoGEO_API`):** 수만 건의 가시성 차이 관측치에서 생성형 엔진의 선호 규칙을 자동 추출하고, 추가 학습 없이 즉시 적용 가능한 프롬프트 기반 모델을 구축했다.
2. **저비용 강화학습 모델(`AutoGEO_Mini`):** 추출된 선호 규칙을 보상 신호로 활용해 경량 모델(`Qwen3-1.7B`)을 GRPO 강화학습으로 훈련해 API 모델 대비 **0.0071배** 비용을 달성했다.
3. **신규 벤치마크 2종 및 협력성(GEU) 평가:** `Researchy-GEO`와 `E-commerce` 벤치마크를 공개하고, 가시성(GEO)과 답변 효용(GEU)을 동시 평가해 평균 **35.99%** 가시성 개선을 입증했다.

## 2. 방법론 (Methodology)

### 2.1 자동 선호 규칙 추출 (4단계 파이프라인 — Algorithm 1)

각 질의 `q`에 대해 생성형 엔진이 생성한 답변 `a`에서 후보 문서들의 객관적 가시성 `Vis(d, a) = Word(d, a) + Pos(d, a) + Overall(d, a)`을 계산한 뒤, 가시성 차이가 가장 큰 문서 쌍 `(dᵢ, dⱼ)`을 선택해 4개 LLM 모듈을 거친다:
1. **Explainer:** 답변 `a`에 비추어 문서 쌍 `(dᵢ, dⱼ)`의 원시 차이를 자연어로 설명.
2. **Extractor:** 설명에서 생성형 엔진 선호에 기여한 핵심 통찰(insight)을 간결하게 추출.
3. **Merger (계층적 병합):** 수만 건의 통찰을 청크 단위로 나누어 재귀적·계층적으로 병합해 반복 패턴을 후보 규칙으로 통합.
4. **Filter:** 모호하거나 우연한 규칙을 걸러내어 진정한 엔진 선호를 반영하는 최종 규칙 집합 `S` 확정.

### 2.2 규칙 기반 GEO 모델 2종
- **`AutoGEO_API` (프롬프트 기반):** 추출된 규칙 집합 `S`를 `"Quality Guidelines to Follow"` 형태로 프런티어 LLM 프롬프트에 삽입해 문서를 재작성(`d̂ = f(d, S)`).
- **`AutoGEO_Mini` (GRPO 강화학습 기반):**
  1. **Cold Start:** 교사 모델(`Gemini-2.5-pro` 기반 `AutoGEO_API`)이 생성한 `(d, d̂)` 쌍으로 경량 모델(`Qwen3-1.7B`)을 지도 미세조정(SFT).
  2. **3대 보상 함수 + GRPO:** 그룹 내 `m`개 후보 재작성 문안에 대해 ① **Outcome Reward (`R_out`)** (GEO 가시성 향상), ② **Rule Reward (`R_rule`)** (추출된 규칙 준수 비율), ③ **Semantic Reward (`R_sem`)** (원문 의미 보존 — KPR + KPC)을 z-점수 표준화해 합산하고 Group Relative Policy Optimization(GRPO)으로 정책을 최적화한다.

## 3. 실험 설정 (Experimental Setup)

- **3개 데이터셋 (각 질의당 ClueWeb22 밀집 검색 상위 5개 문서):**
  - `GEO-Bench`: 학습 8,000 / 테스트 1,000
  - `E-commerce` (신규, LMSYS-Chat-1M 상업 질의): 학습 1,667 / 테스트 416
  - `Researchy-GEO` (신규, Researchy Questions 심층 연구 질의, 정답 포함): 학습 10,000 / 테스트 1,000
- **2대 평가 축:**
  - **GEO:** `Word`, `Pos`, `Overall` (Aggarwal et al., 2024)
  - **GEU (Generative Engine Utility, DeepResearchGym):** 관련성(`KPR`, `KPC`), 충실도(`Precision`, `Recall`), 품질(`Clarity`, `Insight`)
- **평가 생성형 엔진:** `Gemini (gemini-2.5-flash-lite)`, `GPT (gpt-4o-mini)`, `Claude (claude-3-haiku-20240307)` + 적대적 공격 비교군(`Hijack Attack`, `Poisoning Attack`).

### 선호 규칙 분석 및 제거 실험 (Section 5.3 & 5.4)
- **LLM 간 규칙 중복 vs. 도메인 간 규칙 분기 (Figure 2, Table 5):** 같은 데이터셋(Researchy-GEO)에서 Gemini·GPT·Claude 간 규칙 중복도는 **78.95~84.21%**로 높았으나, 오픈 도메인(`Researchy-GEO`–`GEO-Bench`, 88.24%)과 `E-commerce` 간 중복도는 **34.78~40.00%**로 급락했다. 연구 질의는 인과·메커니즘의 심층 설명(`In-Depth`)을, 이커머스는 단계별 실행 가이드(`Step-by-Step Guide`)를 선호했다.
- **제거 실험 (Table 6):** `AutoGEO_Mini`(Overall `38.53`)에서 Rule Reward를 제거할 때(`31.41`) 하락폭이 가장 커, 규칙 기반 보상이 강화학습의 핵심 동인임이 확인되었다.

## 5. 결론 (Conclusion)

AutoGEO는 생성형 엔진의 선호 규칙을 자동 발굴해 프롬프트(`AutoGEO_API`)와 저비용 경량 강화학습 모델(`AutoGEO_Mini`, 비용 0.0071배)로 구현함으로써, 답변 효용(GEU)을 훼손하지 않고 가시성을 극대화하는 협력적 GEO의 실효성을 입증했다.
